## 1. Dart 기본 규칙

[Effective Dart](https://dart.dev/effective-dart/style)를 따른다.

| 대상 | 형식 | 예 |
| --- | --- | --- |
| 클래스 · enum · typedef | `UpperCamelCase` | `Poem`, `ChatMessage`, `Relation` |
| 변수 · 함수 · 매개변수 | `lowerCamelCase` | `poemId`, `loadPoem()` |
| 상수 | `lowerCamelCase` (대문자 금지) | `maxMessageLength` |
| enum 값 | `lowerCamelCase` | `Tone.plain` |
| 파일 · 폴더 | `snake_case` | `reading_screen.dart` |
| private | 앞에 `_` | `_controller` |

### 이름 붙이는 습관

| 종류 | 규칙 | 예 |
| --- | --- | --- |
| bool | `is` · `has` · `can`으로 시작 | `isSaved`, `hasOpenedComparison`, `canSend` |
| 함수 | 동사로 시작 | `savePoem()`, `fetchReading()`, `countReadingDay()` |
| 목록 | 복수형 | `lines`, `badgeIds`, `evidenceLines` |
| 개수 | `~Count` | `empathyCount`, `stopCount` |
| 화면 위젯 | `~Screen` | `ChatScreen` |
| 작은 위젯 | 하는 일 그대로 | `PoemView`, `ChatBubble` |
| 저장소 | `~Repository` | `ReadingRepository` |
| 가짜 구현 | `Fake~` | `FakeReadingRepository` |

줄임말 쓰지 않는다. `msg` ✗ `message` ✓ · `cnt` ✗ `count` ✓ · `btn` ✗ `button` ✓

## 3. 꼭 지킬 것 두 가지

### 행 번호는 1부터

화면에서도 기획서에서도 "6행"이라고 부른다. 코드에서 0부터 세면 모델에게 "6행"을 보내고 실제로는 7번째 줄을 가리키는 버그가 난다.

- **저장·전송되는 모든 행 번호는 1부터**
- 배열에서 꺼낼 때만 `lines[lineNo - 1]`
- 연 구분 빈 줄도 번호를 하나 차지한다 (서시의 마지막 행은 10행)

### `context`를 변수 이름으로 쓰지 않기

Flutter의 `BuildContext`가 이미 `context`라는 이름을 쓴다. 창작 배경을 `context`로 부르면 위젯 안에서 둘이 섞인다. 창작 배경은 항상 **`creationBackground`**.

## 5. Firestore

컬렉션은 **복수형 `lowerCamelCase`**, 필드는 **Dart 모델 필드와 같은 이름**. 모델 이름과 필드 이름이 다르면 변환 코드에서 버그가 생긴다.

```
users/{userId}
  nickname, totalReadingDays, lastCountedDate, badgeIds

users/{userId}/readings/{poemId}
  firstWord, markedLines, conversation, evidenceLines,
  interpretation, isSaved, hasOpenedComparison, isPublic

publicConversations/{conversationId}
  userId, poemId, firstWord, summary, interpretation, empathyCount

publicConversations/{conversationId}/empathies/{userId}
  (공감한 사람 — 중복 공감 방지)

lineStops/{poemId}
  counts: { "1": 3, "6": 7, ... }
```

## 7. 문구

화면에 나오는 한국어 문구는 화면 파일에 직접 쓰지 않고 **`lib/app/strings.dart` 한 곳**에 모은다.

- 문구를 고칠 때 한 파일만 보면 된다
- **"정답", "해설", "올바른"** 이 앱 어디에도 안 들어갔는지 이 파일 하나로 확인할 수 있다

이름은 `화면_무엇` 순서: `homeTotalDays`, `chatHintButton`, `saveLockNotice`

## 8. 커밋 메시지

```
<종류>: <무엇을> (한국어 가능)

feat: 읽기 화면 행 탭 표시
fix: 근거 행 번호가 0부터 저장되던 문제
refactor: PoemView 행 렌더링 분리
docs: README 화면 목록 갱신
chore: http 패키지 추가
```

| 종류 | 쓰는 때 |
| --- | --- |
| `feat` | 기능 추가 |
| `fix` | 버그 수정 |
| `refactor` | 동작은 그대로, 코드 정리 |
| `docs` | 문서 |
| `chore` | 패키지·설정 |
