# 여백 — 계절 테마 설계

새 디자인(하늘색 · 병아리 시안)의 기준. 테마 기반을 만들 때와 각 화면에 테마를 입힐 때 이 문서를 따른다.

## 1. 결정 (2026-11-23)

- **기본 테마** — 하늘색 하늘 · 초록 언덕 · 빨간 목도리 병아리. 시와 상관없는 화면에 쓴다.
- **시 테마** — 시마다 계절이 하나 정해져 있고, 그 시를 다루는 화면은 그 계절로 바뀐다.
- **S08 모두의 대화** — 위쪽 칩으로 고른 시의 테마로 바뀐다. 칩을 누를 때마다 바뀐다.

## 6. 테마 기반 (B가 만든다)

화면 파일은 건드리지 않는다. 이것이 머지돼야 화면 적용을 시작할 수 있다.

| 파일 | 내용 |
| --- | --- |
| `lib/app/theme.dart` | 3장 공통 색 값 교체, `accentDark` · `link` 추가 (주인 A가 리뷰) |
| `lib/app/poem_theme.dart` (새) | `enum Season`, `YeobaekTheme`(4장 토큰 묶음, `defaults` · `spring` · `autumn` · `winter`), `YeobaekTheme.forPoem(poemId)` — 1장 표대로, 모르는 id는 `defaults` |
| `lib/shared/widgets/theme_header.dart` (새) | `ThemeHeader` — 머리 띠 이미지 + 오른쪽 마스코트 + 뒤로 가기 · 제목. 이미지 실패 시 `headerTint` 단색 |
| `lib/shared/widgets/mascot_notice.dart` (새) | `MascotNotice` — 상태 마스코트(잠금 · 빈 화면 · 오류) + 문구 + 버튼 하나. 문구는 화면 주인이 `AppStrings`로 넘긴다 |

## 7. 화면에 입힐 때 규칙 (각 화면 주인)

- 색 코드는 `theme.dart` · `poem_theme.dart`에만. 화면 파일에 `Color(0x…)` 금지 (지침서 그대로)
- 화면 위 머리 띠는 `ThemeHeader`로만. 화면마다 이미지를 따로 깔지 않는다
- 시 화면은 `YeobaekTheme.forPoem(poemId)`로 테마를 얻는다. 계절을 화면에서 직접 고르지 않는다
- 잠금 · 빈 화면 · 오류 안내는 `MascotNotice`로. 평가 기준이 「오류 처리」라 눈에 띄게 둔다
- 시 본문과 사용자 해석은 명조 그대로. 장식이 시 본문을 가리지 않는다
- 이미지는 `errorBuilder`를 둔다. 그림 하나 못 불러온다고 화면이 깨지면 안 된다
- 태블릿에서도 확인한다 (평가를 태블릿으로 한다). 머리 띠 높이는 화면 너비에 비례하지 않게 고정 높이로

## 8. 순서

1. 이미지 등록 (C, #57) — 머지됨
2. 영어 전환 (A, #55)과 테마 기반 (B) — 동시에 가능. 테마 기반은 화면을 건드리지 않는다
3. 각 화면 적용 (화면 주인) — 2가 둘 다 머지된 뒤. 문구와 배치를 같은 화면에서 동시에 고치면 충돌이 난다
4. 뱃지 이미지 (D) — S12 작업 때 `badge_image.dart` · 테스트와 함께
