# 여백 — 이름 대조표

> **✅ main에 적용 완료 (2026-10-07).** `feature/part-b` · `feature/part-d`의 화면을 이 표대로 이름만 바꿔 C 구조(`lib/features/…`)에 옮겼다.
> 화면 내용(배치 · 문구 · 데이터)은 각자 만든 것을 살렸다. **앞으로는 `main`에서 새로 브랜치를 따서 작업한다.**
>
> 왼쪽이 예전 브랜치의 이름, 오른쪽이 지금 쓰는 이름이다. 기준은 `docs/여백-네이밍규칙.md` 2장 용어 사전.

### 적용하면서 정한 것 (예전 ⚠ 항목)

| 항목 | 결정 |
| --- | --- |
| `PoemBadge` | 클래스를 만들지 않는다. `badgeIds`(= `poemId` 목록)만 쓰고 화면은 `BadgeImage` 위젯 |
| 공개 대화 `evidenceLines` · `createdAt` | 넣었다 (근거 구절 표시 · 최신순 정렬). 네이밍규칙에 추가 |
| 전문가 해석 `fullText` | 뺐다. 해석 본문은 `claims`(근거 행 + 주장)로 그린다 |
| `comparisonSentence` | 모델 필드에서 빼고 `FakeData.comparisonTexts`로. 2단계에 비교 모델이 쓴다 |
| `calculateRelationship()` | `lib/compare/relation.dart`의 `computeRelation()`으로 옮겼다 (D 로직 그대로, `Relation` 반환) |
| 색 토큰 | C 브랜치 이름으로 통일 (6장) — A 확인 필요 |
| 뱃지 이름 글자(별 · 꽃 · 고양이) | 화면에서 뺐다 — 뱃지는 문구 없이 이미지만 (기획서 F8) |
| D 데이터의 '조용한 별' | 내 닉네임(화면분업 기준)과 겹쳐 그 사용자는 '새벽의 별빛'으로 |
| S08 해석 미리보기 상자 | 왼쪽 선만 있는 테두리에 둥근 모서리를 주면 Flutter가 오류를 내서 모서리를 뺐다 |

### 화면이 받는 값 — 가장 중요

라우트가 `/poems/:poemId`처럼 **문자열 id**만 넘기므로, 화면은 객체가 아니라 **id를 받고 안에서 찾아 쓴다.**

| 화면 | 지금 받는 것 | 바꿀 것 |
| --- | --- | --- |
| S04 | `Poem poem` | `String poemId` |
| S06 | `Poem poem`, `List<String> myMessages`, `List<int> groundedLines` | `String poemId` (나머지는 `Reading`에서 꺼냄) |
| S07 | `Poem poem`, `String myInterpretation`, `List<int> myGroundedLines` | `String poemId` |
| S08 | `String poemId`, `String poemTitle` | 없음 (탭 화면. 시는 화면 안의 칩으로 고름) |
| S09 | `CommunityPost post` | `String conversationId` |
| S12 | `UserProfile? profile`, `bool isMe` | `String userId` (내 것인지는 `userId == 내 id`로 판단) |

토큰 이름은 문서에 없다. 아래는 C 브랜치 `theme.dart` 기준 제안이다.

| 지금 | 바꿀 이름 | 값 |

## 7. 그 밖에 맞출 것

- 화면 안의 한국어 문구 → `lib/app/strings.dart`의 `AppStrings`로 (예: `'같은 곳을 봤어요'` → `AppStrings.comparisonRelationSameLines`)
- 관계 문구를 만드는 코드는 모델이 아니라 화면이나 D의 `compare/`에서 `Relation` → 문구로 바꾼다
- 테스트 파일 `test/part_b_test.dart`는 클래스 이름이 바뀌면 같이 고친다

## 통합 순서

1. 이 표에서 ⚠ 항목을 팀이 정한다
2. C가 `feat/app-stage1-screens`를 `develop`에 올린다 (라우터 · 탭바 · 테마 · 모델 · 가짜 데이터의 기준)
3. B · D가 각자 브랜치를 `develop` 위로 옮기면서 이 표대로 이름을 바꾸고, 자기 화면 파일만 C 브랜치의 같은 파일에 덮어쓴다
4. 앱을 켜서 S01부터 끝까지 눌러본다 (`docs/여백-화면분업.md` 5장 완료 기준)
